# Random-Password-Generator
A secure and user-friendly Random Password Generator built with Python and Tkinter. The application allows users to create strong, customizable passwords based on length and selected character types.
It uses Python's secrets module for cryptographically secure password generation and provides useful features such as password strength analysis, automatic clipboard copying, ambiguous-character exclusion, and session-based generation history.

 Features
Password length control (8–50 characters)
Uppercase and lowercase character selection
 Number and symbol selection
 Secure password generation using secrets
 Minimum two character types required
 Guarantees at least one character from every selected type
 Password strength indicator (Weak / Medium / Strong)
 Automatic copy to clipboard using pyperclip
 Option to exclude ambiguous characters (0, O, l, 1)
 Displays the last 5 generated passwords during the current session
 Generate multiple passwords without restarting
Input validation and error handling
Simple graphical user interface built with Tkinter

Technologies Used
Python
Tkinter
Secrets
String
Pyperclip

Project Goal
The project demonstrates secure password generation, GUI development, user input validation, and basic security practices using Python.
